Abstract

This document specifies the Theater Showtimes Application Profile, a specific application profile (SAP) of the Culture Information Model (DRK IM) developed for the German Culture Dataspace (Datenraum Kultur, DRK). The profile defines how the classes, properties, and controlled vocabularies of the Culture (DRK) Ontology [[DRK-ONTOLOGY]] are to be combined, constrained, and reused to describe metadata about theatrical play productions, theater events (showtimes), the venues at which they take place and their accessibility, the roles and performers involved, and the associated offers and price specifications.

The profile reuses Schema.org [[SCHEMA-ORG]] as its foundational vocabulary, integrates DCAT [[vocab-dcat-3]] for data service and distribution metadata, and reengineers A11yJSON [[A11YJSON]] for describing the accessibility of cultural places. Conformance is expressed through cardinality constraints and validated using SHACL [[shacl]] shapes.

Status of this document

This is a working draft prepared in support of the revision of the DRK Information Model paper submitted to the Semantic Web Journal (SWJ). It is published as an unofficial document and does not represent a W3C standard. It follows the structure and editorial conventions of mobilityDCAT-AP [[MOBILITYDCAT-AP]] so that the two profiles can be read consistently.

The cardinality (Card.) and obligation values in this draft are provisional. Only the constraints already formalised in the published SHACL shapes (for drk:PlayProduction) are fixed; all remaining values are marked TBD and will be populated from the representative-cardinality analysis and the extended SHACL shapes once available.

Introduction

Context

The Culture (DRK) Ontology is the semantic backbone of the Culture Dataspace. It provides an extensible, modular vocabulary for describing metadata in the cultural domain, enabling interoperable, sovereign, and semantically rich data sharing across cultural sectors. It defines common, domain-agnostic modules—for organizations, places and accessibility, creative works, events, roles, and data services—together with domain-specific modules, of which theater showtimes is the first and most developed.

In a dataspace, a data provider registers a data asset (for example, a Theater Showtimes API) by describing it with metadata that enables discovery. This application profile governs the culture-domain-specific part of that metadata: the description of the play productions, their performances (showtimes), and the venues and offers attached to them.

Scope and application-profile methodology

The DRK IM is developed following an application-profile-first (AP-first) methodology. Two kinds of profile are distinguished:

  • General Application Profile (GAP) — a convention-based set of recommended concepts and attributes with common, minimum constraints, foreseen to be applicable to all specific applications derived from it.
  • Specific Application Profile (SAP) — a profile for a concrete use-case scenario with concrete data providers and data sources, derived from a GAP.

This document is the Theater Showtimes SAP. Its scope is the metadata required to describe and discover theatrical showtimes published by performing-arts theaters; it does not cover the content data exchanged peer-to-peer once an asset has been discovered, nor the access- and usage-policy layer, which is handled separately through the DRK ODRL profile.

Conformance

This section is normative. The key words MUST, MUST NOT, REQUIRED, SHOULD, SHOULD NOT, RECOMMENDED, MAY, and OPTIONAL in this document are to be interpreted as described in [[rfc2119]] and [[rfc8174]].

An RDF graph conforms to this profile if, for every entity it contains that is typed with a class defined or reused by this profile, it satisfies the cardinality and value constraints stated in the corresponding properties table (§) and validates against the associated SHACL shapes. The obligation of a property is derived from its cardinality as follows:

ObligationCardinality (min..max)Meaning
mandatory1..1, 1..nThe property MUST be present at least once.
recommended0..1, 0..nThe property SHOULD be present where the information is available.
optional0..1, 0..nThe property MAY be present.

Where 0..1 / 0..n appears, the distinction between recommended and optional is given in the property's Usage note column.

Conceptual model

The Theater Showtimes profile is centred on the separation between a play production (a creative work, covering writing, planning, casting, staging, and rehearsal) and a theater event (a showtime, i.e., the presentation of that work at a given place and time). A production is performed at one or more events; each event takes place at a performing-arts theater (a place with accessibility features) and carries one or more offers with their price specifications. Both productions and events attach roles (character roles and production/event roles), each of which links to a performer.

Validation

Conformance is checked with SHACL [[shacl]] shapes maintained in the repository. The current published shapes constrain drk:PlayProduction to require at least one schema:name, at least one schema:description, and at least one schema:genre drawn (as an IRI) from the Theatrical Genres vocabulary. The example below illustrates the constraint: 

drk:PlayProductionShape
    a              sh:NodeShape ;
    sh:targetClass drk:PlayProduction ;
    sh:property    [ sh:path schema:name ;        sh:minCount 1 ] ;
    sh:property    [ sh:path schema:description ; sh:minCount 1 ] ;
    sh:property    [ sh:path     schema:genre ;
                     sh:minCount 1 ;
                     sh:nodeKind sh:IRI ;
                     sh:in       ( tgenres: ) ] .

The full shape graph covering the remaining classes and the cardinalities tabulated above is in preparation and will be linked from the alternate formats when complete.

Example

The following abbreviated example shows a play production, a showtime, the venue with accessibility features, and a ticket offer, following this profile. The complete, runnable instance is available in the repository (examples/theater-metadata-instance.ttl). The data is illustrative and may not be factually correct. 

drkr:DE_STAugsburg_HedwigAngryInch
    a                  drk:PlayProduction ;
    schema:name        "Hedwig and the Angry Inch"@en ;
    schema:description "Songs in English with German dialogues …"@en ;
    schema:genre       tgenres:Musical ;
    drk:productionType tprod:Revival ;
    schema:inLanguage  lang:de ;
    drk:creatorRole    [ a               drk:ProductionRole ;
                         schema:roleName "Director"@en ;
                         drk:performer   [ a                 drk:Performer ;
                                           schema:name       "Cornelia Maschner"@en ;
                                           drk:performerType tperf:Person ] ] .

drkr:HedwigAngryInch_Event_20241228
    a                    drk:TheaterEvent ;
    schema:name          "The last performance of Hedwig and the Angry Inch …"@en ;
    schema:workPerformed drkr:DE_STAugsburg_HedwigAngryInch ;
    schema:location      drkr:DE_Augsburg_STAugsburg_Place ;
    schema:startDate     "2024-12-28T19:30:00"^^xsd:dateTime ;
    schema:endDate       "2024-12-28T21:00:00"^^xsd:dateTime ;
    schema:duration      "PT1H30M"^^xsd:duration ;
    drk:intermissionCount "0"^^xsd:nonNegativeInteger ;
    drk:subtitleLanguage lang:de, lang:en ;
    drk:eventType        tevent:LastPerformance ;
    schema:eventStatus   schema:EventScheduled ;
    schema:offers        [ a                   schema:Offer ;
                           schema:name         "Standard Ticket Offer"@en ;
                           schema:availability schema:InStock ;
                           schema:priceSpecification
                             [ a                    schema:PriceSpecification ;
                               schema:minPrice      11.0 ;
                               schema:maxPrice      29.0 ;
                               schema:priceCurrency fibo-fnd-acc-4217:EUR ] ] .

    a                           drk:PerformingArtsTheater ;
    schema:name                 "Staatstheater Augsburg – brecht stage im Gaswerk"@en ;
